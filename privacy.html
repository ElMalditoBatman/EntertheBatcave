🔒 Privacy Policy

Last updated: July 23, 2026

Overview

Enter the Batcave ("the App") is a personal health data dashboard operated by ElMalditoBatman. This Privacy Policy explains how the App accesses, uses, and stores your Google Health data.

Data Access & Permissions

The App requests the following read-only scopes from Google Health API:

Scope Data Accessed Purpose
googlehealth.activity_and_fitness.readonly Steps, distance, active minutes, calories burned Display daily activity summaries
googlehealth.sleep.readonly Sleep duration, sleep stages, sleep quality Display sleep metrics and trends
googlehealth.nutrition.readonly Food logs, macronutrient breakdowns Display nutrition tracking
googlehealth.health_metrics_and_measurements.readonly Heart rate, weight, body composition, blood pressure Display health metric trends
googlehealth.profile.readonly Basic profile information (age, sex, height) Contextualize health metrics
googlehealth.settings.readonly Health platform preferences and data source settings Configure data sources

Data Storage

All data is stored locally on the user's own private server. OAuth tokens are stored in a local encrypted file. No data is sent to any third-party server, analytics service, or external API other than the Google Health API itself.

Data Usage

Your data is used exclusively for:

  • Displaying health metrics on your personal dashboard
  • Generating daily/weekly health summaries
  • Aggregating activity trends over time

Data is never sold, shared, or used for advertising.

Data Retention

OAuth tokens are retained until you revoke them via myaccount.google.com/permissions. Cached health data is stored on your local server until you delete it.

Third-Party Services

This App communicates with Google Health API (Google LLC) solely for the purpose of retrieving your health data. Google's privacy policy applies to data transmitted to their servers during OAuth authentication and API calls.

Security

OAuth tokens are stored with restricted file permissions (0600) on a private Linux server. The App does not expose any public endpoints. All API communication uses HTTPS.
